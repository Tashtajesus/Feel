аквариумистика; RU + EN), найти приёмы, которые работают при простой съёмке на
телефон, и дать 100 идей. Логин и защиту Instagram не обходим.

## Способы сбора

**A. Только vidIQ (можно начать сразу).**
До ~15–19 поисковых запросов (75–95 кредитов) по RU/EN-запросам за 12 месяцев,
`collapseByCreator: false`, `resultsPerPlatform: 100`, порог просмотров снижен.
Ограничения: выборка из индекса «выбросов» смещена к успешным роликам (нижние 20% —
это «слабые среди сильных»); видео не скачиваются, разбор — по подписи, обложке и
метаданным; «посмотреть» по 10 кредитов — хватит на единицы роликов.
Сколько уникальных роликов наберётся — станет ясно после первых запросов.

**B. Apify (полное ТЗ).**
Нужно в настройках облачной среды (меню среды в заголовке сессии → Edit):
1. Переменная окружения `APIFY_TOKEN` — токен Apify (не присылать в чат).
2. Network access → Custom, добавить в Allowed domains, сохранив список пакетных
   менеджеров: `api.apify.com`; для скачивания видео — `*.cdninstagram.com`,
   `*.fbcdn.net`; для модели whisper — `huggingface.co`, `*.huggingface.co`, `*.hf.co`.
   Инструкция: https://code.claude.com/docs/en/cloud-environments#network-access
3. Начать новую сессию — она подхватит токен и сеть.
Актёры: Instagram Hashtag Scraper / Instagram Reel Scraper (ролики),
Instagram Profile Scraper (подписчики авторов). Оплата — на стороне Apify по числу
результатов.

**C. Ссылки от пользователя.** Подходит как дополнение; без доступа к сети видео всё
равно не скачать.

## Конвейер (одинаковый для A и B)

1. Сбор → `raw/<источник>_<запрос>.json` (сырые ответы, чтобы можно было продолжить).
2. Сведение и дедупликация по shortcode → `data.csv`:
   `url, account, followers, views, likes, comments, duration_s, date, caption,
   hashtags, audio, source, query`.
3. Вирусность = views / followers. Топ-30% и нижние 20% → `segments.csv`.
4. Разбор топ-300 → `labels.csv`: хук 1–3 с (визуальный / текстовый / звуковой),
   формат, кто в кадре, склейки, текст на экране, озвучка, длина, призыв,
   сложность 1–5, `analysis_basis` (видео / только метаданные).
   - B: скачать видео, кадры 0 / 1 / 3 с и середина (ffmpeg), расшифровка (whisper).
   - A: по подписи, обложке и метаданным.
5. Сравнение топа и низа в цифрах → `report.md`.
6. 100 идей по рубрикам → `ideas.md`.

Перед шагом 4 (скачивание сотен видео) — показать план и получить подтверждение.
