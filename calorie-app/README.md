# Feel — счётчик калорий

Веб-приложение в духе Cal AI: сфотографировал тарелку — получил калории и БЖУ.
Работает в браузере телефона, можно добавить на главный экран как приложение.

## Возможности

- **📸 Калории по фото.** ИИ (Claude) находит на фото каждое блюдо, оценивает вес порции
  и пищевую ценность. Граммы и названия можно поправить перед сохранением, а также дописать
  уточнение («без сахара», «2 яйца») и пересчитать.
- **🔎 База продуктов.** ≈270 популярных продуктов и блюд (крупы, мясо, молочка, супы, фастфуд,
  напитки…) прямо в приложении, работает без интернета. Плюс поиск по мировой базе
  **Open Food Facts** (миллионы упакованных товаров).
- **▥ Штрихкод.** Сканирование камерой (Chrome на Android) или ввод цифр вручную — данные
  берутся из Open Food Facts.
- **✍️ Ручной ввод** калорий и БЖУ.
- **Калькулятор нормы** от тела и цели:
  - % жира по замерам шеи, талии и бёдер (формула ВМС США) или введённый вручную;
  - сухая масса тела, ИМТ, отношение талии к росту, здоровый диапазон веса для роста;
  - базовый обмен по Кэтчу — МакАрдлу (если известен % жира) или Миффлину — Сан Жеору;
  - расход с учётом активности, дефицит/профицит под выбранный темп (кг в неделю);
  - белки, жиры и углеводы под цель, прогноз даты достижения желаемого веса;
  - защита от крайностей: не ниже безопасного минимума калорий, предупреждения о слишком
    быстром темпе и нездоровом желаемом весе.
- История замеров (талия, бёдра, шея, % жира) на экране «Прогресс».
- Остаток калорий, белков, жиров и углеводов, вода, приёмы пищи, история по дням.
- **Прогресс:** график калорий за неделю, график веса, серия дней.
- Тёмная тема, экспорт/импорт данных. Все записи хранятся только в браузере.

## Запуск

Нужен Node.js 18+ и ключ API Anthropic (https://console.anthropic.com/).

```bash
cd calorie-app
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

Откройте http://localhost:3000. Порт меняется переменной `PORT`.

### Переменные окружения

| Переменная | Что делает |
|---|---|
| `ANTHROPIC_API_KEY` | ключ API Anthropic, обязателен для распознавания фото |
| `ACCESS_CODE` | необязательный код доступа: без него чужие люди смогут тратить ваш баланс API |
| `HOURLY_LIMIT` | лимит распознаваний в час с одного IP (по умолчанию 60) |
| `PORT` | порт сервера (хостинги задают сами) |

## Хостинг на Render (бесплатно)

1. Зарегистрируйтесь на https://render.com через GitHub.
2. **New → Blueprint**, выберите репозиторий `feel` — Render найдёт `render.yaml` в корне.
3. Введите `ANTHROPIC_API_KEY` и придумайте `ACCESS_CODE`, нажмите **Apply**.
4. Через пару минут появится адрес вида `https://feel-calories.onrender.com`. Откройте его
   на телефоне → «Поделиться» → «На экран Домой».

На бесплатном тарифе сервер засыпает после 15 минут простоя, первое открытие
после этого занимает ~30–50 секунд. Сами записи хранятся в телефоне, они не пропадут.

Другие варианты: в папке есть `Dockerfile` — подойдёт для Railway, Fly.io,
Timeweb Cloud или любого VPS. Камера и сканер штрихкодов работают только по HTTPS.

## Как устроено

- `server.js` — небольшой сервер без фреймворков: раздаёт `public/` и обрабатывает
  `POST /api/analyze` (фото → Claude → JSON со списком продуктов). Ключ API остаётся на сервере.
- `public/app.js` — всё приложение на чистом JS, данные в `localStorage`.
- `public/foods.js` — встроенная база продуктов (на 100 г).
- `public/sw.js` — офлайн-кэш, чтобы приложение открывалось без сети.

Фото перед отправкой сжимаются до 1024 px; одно распознавание стоит порядка
нескольких центов по тарифам API.
